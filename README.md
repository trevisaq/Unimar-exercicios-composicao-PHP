## Instruções de execução

Para executar qualquer exercício (`ex01` até `ex10`):

1. Tenha o **PHP** e o **Composer** instalados.
2. Abra o CMD na pasta do exercício desejado.
3. Execute o comando:

   ```bash
   php index.php
   ```

**Observações:**
- Não é necessário executar `composer install` ou `composer init`, pois os arquivos necessários já estão incluídos.
- Para testar as funcionalidades, consulte o `index.php` de cada exercício. Alguns testes podem estar comentados e prontos para uso.
